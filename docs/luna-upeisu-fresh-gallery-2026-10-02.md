Two release gates are clear:

1. The first Luna run promoted online election voting start/end notices into two-hour physical events at UPEISU. The saved legacy result also retained voting start, so this is a shared eligibility weakness. A general exact-post Luna safety rule now holds administrative voting/registration/application/nomination start or end notices with remote evidence and no physical place. A website in `spatial.locations` is not treated as a physical place. Build and nine focused tests pass. The second full-path run exercised the first version of this rule and held one milestone; the other represented `myupei.ca` as an online spatial location. The final rule removes both from that saved result in offline replay. The third full-path repeat returned exactly the 18 source-worthy listings and zero online milestones, but its primary extraction had already omitted the two milestones, so it did not exercise the final guard. The later production selected-row dry run below exercised the website-venue guard end to end. Scheduled parser routing remains on GPT-5.2.
2. The first Luna dry-write preview could not resolve `The UPEI Turf` for October 3 or `Day Lounge` for October 29. Both are real source listings. The legacy record had `UPEI Turf` without its leading article, so its venue matched. The venue matcher now tries the printed name first, then a candidate without a leading `The`; the 13 focused venue tests pass. A new dry-write preview maps October 3 to the existing `slug_upeiturffield` and produces 17 of 18 source-worthy payloads. `Day Lounge` remains held, as it was in the saved legacy payload preview. [UPEI identifies the Day Lounge within W.A. Murphy Student Centre](https://d9.upei.ca/student-supports-and-services/student-culture-and-community-standards/campus-life-program), but the current venue record does not match that room label. Map it through a reviewed venue alias or room relationship; do not silently treat every unidentified room as the organizer's location. [UPEI also lists the Turf Field as a facility](https://www.upei.ca/ar/athletic-facilities/facility-schedules/turf-field).

The source states only start times for the October 3 Go! Experience and October 10 drag show. Luna's two-hour ends are labeled parser defaults, while the saved legacy output assigned 11 PM to the October 3 event. Neither end time is printed. Luna's final records kept all calendar entries nonrecurring; the saved legacy result incorrectly marked the October 7 financial literacy workshop weekly. This reinforces the existing code-side recurrence gate.

Do not enable broad Luna routing from this one blind gallery. The next step is one more fresh layout case with a dry-write preview, followed by a small allowlisted live pilot. This comparison establishes 17 source-worthy, write-eligible Luna records against 13 in the saved legacy replay, with the same Day Lounge venue hold. The exact-post pilot can then be judged on source-worthy records and write eligibility rather than final parser count alone.
