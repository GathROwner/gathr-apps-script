## Learning cases retained

1. Joint sites need a canonical destination or an explicit supported shared-site
   representation; don't produce two duplicate events or merge businesses.
2. Collection partners, organizer offices and attendee distribution venues have
   different roles. New venue proof doesn't settle conflicting clocks.
3. Registration opening, in-person signup and first programme session are separate
   date roles. Weekly recurrence must respect actual commencement.
4. Preserve row-to-day-heading context and festival prefixes through extraction.
   Explicitly supported festival rows must not fail solely because fields discard
   the shared heading. A future fix needs a reproduction and healthy controls.
5. Relative dates require exact original occurrence anchoring; image festival awards
   and unrelated years must not supply the event's year.
6. Conflicting versions need source-role/recency evidence; do not invent a universal
   caption-over-poster or website-over-poster priority.
7. Same title/activity with different clocks is an occurrence-identity issue before
   it is a duplicate decision. Never revive expired/missing children to fill links.

These are documented observations, not a claim those general parser fixes are
implemented. Keep equivalent future cases connected to these mechanisms; preserve
the evidence needed to compare repeated failures. Do not spend further recovery
effort on these unchanged source versions. New independent evidence can reopen a
case; a new dataset ID or signed CDN URL alone is not new semantic evidence.
